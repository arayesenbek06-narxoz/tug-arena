# 🪢 TUG ARENA

**Tug Arena** is a browser-based tug-of-war game where the player competes against a bot using stamina and strategic pulls.

## 🎮 How to Play

The goal is to pull the marker toward your side before the 30-second timer ends.

- **PULL** — performs a normal pull.
- **POWER PULL** — performs a stronger pull but consumes more stamina.
- Watch your **stamina bar** and use your energy strategically.
- The bot pulls automatically.
- Win by moving the marker far enough toward your side before time runs out.

## ⌨️ Controls

- `SPACE` — Pull
- `E` — Power Pull
- You can also use the on-screen buttons.

## ⚡ Game Features

- Player vs Bot gameplay
- 30-second game timer
- Stamina system
- Normal and Power Pull attacks
- Dynamic tug-of-war position
- Win and lose screens
- Rematch option
- Keyboard and button controls

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 📁 Project Structure

- `index.html` — main structure of the game
- `style.css` — visual design and layout
- `script.js` — game logic and interactions

## 🚀 Running the Project

1. Download or clone the repository.
2. Open `index.html` in a web browser.
3. Click **PLAY**.
4. Start pulling and try to beat the bot!
